# Projeto Orçamento Pessoal

Este projeto é um sistema simples de **controle de despesas pessoais**, 
desenvolvido durante o _Curso de Desenvolvimento Web Completo_ da **Udemy**. 
O objetivo é registrar e consultar despesas de forma prática, facilitando a
organização financeira pessoal.

## 📋 Funcionalidades

- ✅ Cadastro de despesas com:
  - Data
  - Tipo da despesa (como alimentação, transporte, saúde etc.)
  - Descrição
- ✅ Consulta das despesas cadastradas
  - Filtro por período, tipo ou descrição
  - Visualização em tabela
- ✅ Armazenamento local via `localStorage`, sem necessidade de banco de dados

## 🛠 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Puro)**
- **Bootstrap** (para o layout responsivo)
- **localStorage** (para persistência dos dados no navegador)
